# 这是一个特别特别长的文档标题用来验证左栏放不下的时候会不会显示完整

这篇文档只做一件事：给左栏一个**放不下的标题**，验证长标题的显示方式。
左栏宽度固定 320px，写不下的标题是会一直被省略号盖住的——所以它需要一条专门的出口。

## 左栏怎么显示放不下的标题

- 常态：条目按左栏宽度排版，放不下的部分截断成省略号；
- 鼠标悬停（或键盘 <kbd>Tab</kbd> 聚焦）：省略号让位，**标题在原来这一行里往右伸出左栏**显示完整，
  不再弹气泡；展开时条目底色会跟着铺到标题末尾，所以压在正文上照样看得清；
- 左栏是纵向滚动区，展开的那条是画在左栏外面的（留在里面会被裁在左栏边上），所以横向不会冒出滚动条；
- 手机上左栏是抽屉，没有悬停这回事（手指点条目就是跳转），所以保持省略号。

## 顺带压到的几个边界

| 清单里那条标题的形态 | 看什么 |
| --- | --- |
| 顶层超长中文标题 | 展开后是否真的伸出左栏、有没有盖住正文那一行的字 |
| 没有空格的长英文串 | 左栏不会因此冒出横向滚动条 |
| 三级嵌套的长标题 | 可用宽度更窄时同样成立 |
| 长标题外链 | 结尾的 `↗` 跟着一起伸出去，位置正常 |
