# 欢迎

这里是 **MarkdownToWebSite** 的演示站点，同时也是它自己的使用说明：
左栏的目录、右栏的「本页大纲」、代码复制、图片放大，都是这套东西渲染出来的。
它没有构建步骤——`index.html`（外壳）+ `app/`（三个文件）+ `docs/`（全部内容）丢进任意静态服务器就能读。

## 快速开始

```bash
python3 -m http.server 8080     # 在仓库根目录执行，然后打开 http://localhost:8080/
```

> **必须走 HTTP**：正文是 `fetch()` 出来的，双击 `index.html`（`file://` 协议）会因同源策略读不到 Markdown。
> 这也正是它按 nginx 静态目录部署来设计的原因。

目录怎么摆、内容根是什么，见 [快速开始](指南/快速开始.md)。

## 站点由三部分组成

| 位置 | 是什么 | 说明 |
| --- | --- | --- |
| `docs/`（本目录） | 全部内容 | 正文、图片、`_sidebar.md` 都在这里，可以整包搬去别的项目 |
| `index.html` | 配置外壳 | 一个 `window.MD_SITE` 配置 + 三个 DOM 容器，要改配置只改这里 |
| `app/` | 三个文件 | 解析器 / 应用 / 样式，零依赖、无 CDN |
