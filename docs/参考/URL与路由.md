# URL 与路由

## 路由规则

| 写法 | 打开的文件 |
| --- | --- |
| `#/` | `home`（默认 `README.md`，本站是 `docs/README.md`） |
| `#/指南/快速开始` | `docs/指南/快速开始.md`（`.md` 后缀可省） |
| `#/指南/快速开始.md` | 同一个文件，带后缀也认 |
| `#/指南/` | `docs/指南/README.md` —— 目录的落地页统一叫 `README.md` |
| `#/指南/README` | 同一个文件（左栏点「指南总览」用的就是这个写法） |
| `#/路径#锚点` | 定位到标题锚点，刷新仍能定位 |
| `#/路径?id=锚点` | 同上，docsify 的老链接形式 |
| `#/../README.md` | 404 页：越出内容根的路由不会被渲染 |

## 正文里的链接会变成什么

- 相对链接按**当前文档目录**解析：[快速开始](../指南/快速开始.md) 点击后地址栏变成 `#/指南/快速开始`；
- 页内锚点会带上路径：[跳到「表格」](../指南/写内容/支持的语法.md#表格) → `#/指南/写内容/支持的语法#表格`；
- 外链（`http://`、`https://`、`mailto:` 等）新窗口打开，不参与站内路由；
- 站内链接没有 `.md` 后缀时会自动补上，所以指向图片等静态文件的链接会 404
  （原因见 [链接与图片](../指南/写内容/链接与图片.md)）。

## 内容根是边界

- 内容根由 `index.html` 里的 `root` 指定（本站是 `'docs'`），一切路径都相对它；
- `..` 允许在根内上行：`#/参考/../参考/项目结构.md` 与 `#/参考/项目结构.md` 是同一篇
  （左栏高亮与缓存也按归一化后的路径算）；
- 越出内容根的 `..` 直接被拦下：`#/../README.md` 得到 404 页，**请求根本不会发出去**，
  仓库根目录的项目 `README.md` 不会被渲染进站点。

## 404 页

请求的文档不存在时显示 404 页，而不是白屏：

- 回显请求的路径；
- 列出可访问的候选文档；
- 提供「回到首页」；
- 左栏照常可用，点任何一篇就能恢复。

## 地址栏与历史

站点是单页应用，一切都在 hash 里：

- 刷新 = 冷启动，同一篇文档、同一锚点仍能定位；
- 前进 / 后退回到之前的文档，左栏高亮同步跟随；
- 同一篇文档反复来回切换不会重复请求（内存里带缓存）。
