# 界面与移动端

## 三栏

| 区域 | 放什么 | 宽屏（≥1400px） |
| --- | --- | --- |
| 左栏 `#sidebar` | 只列 `_sidebar.md` 里的**文档条目**，分类可折叠 | 常驻（sticky） |
| 中栏 `#main` | 正文 | 自适应 |
| 右栏 `#toc` | 本页大纲（收录哪些级别由配置里的 `toc` 决定） | 常驻（sticky） |

页面大纲**只在右栏**，左栏不会重复挂一遍标题，原因见 [侧栏清单](../指南/侧栏清单.md)。

三栏里只有左栏自带底色：`--bg-sidebar`（浅色 `#fff`，深色 `#1a1e23`，比正文略亮）。中栏与右栏都跟正文同底色
`--bg`（浅色 `#fff`、深色 `#15181c`），右栏靠那 1px 左边框与正文分区；灰只在需要指出的地方出现——条目悬停、
表头、顶栏按钮悬停，以及长标题展开的那条横条，它们用的是另一支变量 `--bg-toc`。
窄屏下大纲收成浮层，底色不变，跟正文的分界交给阴影与左边框。

## 断点

| 宽度 | 左栏 | 右栏大纲 |
| --- | --- | --- |
| ≥1400px | 常驻 | 常驻 |
| 768–1399px | 常驻 | 顶栏「大纲」浮层 |
| <768px | 抽屉（☰ 打开） | 同一套「大纲」浮层 |

- 抽屉与浮层共用一层遮罩：点遮罩、按 `ESC`、或选中文档后自动收起；
- 浮层里的条目点一下就会跳转并收起，跳转后大纲高亮随之定位。

## 手机上做了什么

- 抽屉与浮层的高度按 `dvh` 计算，浏览器地址栏伸缩不会把底部切掉；
- 刘海与「小白条」用 `env(safe-area-inset-*)` 避让；
- 顶栏按钮在窄屏放大，手指点得准；
- 宽表格改成横向滚动，不会把行内代码挤成竖排；
- 手机上左栏是抽屉，没有悬停这回事（手指点条目就是跳转），长标题保持省略号，不做展开。

## 代码、图片、主题

- **代码块**：右上角有语言标签与复制按钮（Clipboard API，失败时降级并给出提示）；
- **图片**：点击放大，再点、点背景或按 `ESC` 关闭，见 [链接与图片](../指南/写内容/链接与图片.md)；
- **长标题展开**：左栏宽度固定，放不下的标题截断成省略号；鼠标悬停（或键盘 `Tab` 聚焦）时省略号让位，
  标题**在原来这一行里往右伸出左栏**显示完整——不再是浮在条目上方的气泡，而是那一行自己往外延伸：
  左栏是纵向滚动区，横向溢出会被它裁掉（`overflow-x: clip` 与 `overflow-y: auto` 搭配时会按 `hidden` 计算），
  纯 CSS 伸不出去，所以由 JS 把条目原位复刻成一条 `position: fixed` 的横条（`#sidebar-expand`）：
  位置、字号、底色都跟条目一致，底色不透明（当前条目本是半透明绿底，会先铺一层实底），
  条目自己被截断的那行正好被它盖住，压在正文上也看得清；横向不产生滚动条，
  条目没在左栏里整条露着（滚到半截）时不铺，手机没有悬停、窄窗的抽屉里也不铺，都保持省略号；
- **主题**：`auto` 跟随系统 `prefers-color-scheme`，顶栏按钮可强制浅色 / 深色，选择存在 `localStorage`；
- **滚动高亮**：右栏大纲跟随正文滚动，点条目平滑跳转——同篇内跳锚点不会重新请求文档。
