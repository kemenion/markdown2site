## 两条铁律

1. **路径一律相对内容根**：正文里的链接、图片、`_sidebar.md` 里的条目都从内容根算起，与 `index.html` 在哪无关；
2. **内容根是边界**：`..` 只能在根内上行，越界一律 404，仓库里别的文件不会被渲染进来。

> 完整表格与例子见 [URL 与路由](URL与路由.md)。
