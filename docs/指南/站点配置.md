# 站点配置

站点的行为全部由 `index.html` 里的一个对象决定——页面里没有别的配置，也没有环境变量：

```js
window.MD_SITE = {
  name: '阅读收集',        // 顶栏标题；留空则取 _sidebar.md 里第一个文档的标题
  home: 'README.md',       // 首页文件（#/ 打开它）
  root: 'docs',            // 内容根：正文 / 图片 / _sidebar.md 都在它下面；'' = 与 index.html 同级
  sidebar: '_sidebar.md',  // 左栏清单（相对内容根）
  toc: [2, 3],             // 右栏大纲收录的标题级别；[] = 关闭
  sidebarExpanded: 'all',  // 左栏分类初始展开：'all' / 'none' / ['指南', '指南/写内容']
  cacheVersion: 'v1',      // 破缓存版本号，会拼到所有请求上
  theme: 'auto'            // auto | light | dark
};
```

## 配置项

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `name` | `''` | 顶栏标题；留空则回落到 `_sidebar.md` 里第一个文档的标题 |
| `home` | `README.md` | `#/` 指向的文件，相对内容根 |
| `root` | `''` | 内容根目录，例如 `docs`；边界规则见 [快速开始](快速开始.md) |
| `sidebar` | `_sidebar.md` | 左栏清单文件，相对内容根 |
| `toc` | `[2, 3]` | 右栏大纲收录哪些级别，`[]` 关闭；左栏不挂大纲，见 [侧栏清单](侧栏清单.md) |
| `sidebarExpanded` | `'all'` | 左栏分类的初始展开策略，本站即「全部展开」，见 [侧栏清单](侧栏清单.md) |
| `cacheVersion` | `''` | 破缓存版本号，内容更新后加一即可 |
| `theme` | `auto` | `auto` 跟随系统 / `light` / `dark` |

## 改完怎么生效

1. 只改 `index.html` 里的这一段，`app/` 一概不用动；
2. 内容更新后把 `cacheVersion` 加一（例如 `v1` → `v2`）：它会拼到每一个 `fetch` 上，绕开浏览器缓存；
3. 刷新页面。站点是纯静态的，「部署」就等于把文件覆盖到服务器上。

## 主题与大纲

- `theme: 'auto'` 时跟随系统的 `prefers-color-scheme`；顶栏的 🌙 / ☀️ 按钮可以强制浅色或深色，
  选择记在 `localStorage` 的 `md-site-theme` 里，刷新后仍然生效；
- `toc` 决定右栏收哪些级别（本站是 h2 + h3），而**左栏永远只有文档条目**；
- 窄屏下左栏与大纲怎么变（抽屉 / 浮层）见 [界面与移动端](../参考/界面与移动端.md)。
