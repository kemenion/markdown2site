# 支持的语法

这一篇把常用的写法都写了一遍：你看到的右栏大纲、表格、代码块、脚注，全部由下面的源码渲染而来。
正文只依赖 `app/markdown.js` 这个零依赖解析器——**没有插件、没有构建**，只有三处少量拓展：
提示区块 `::: tip` 等、代码块行高亮 `{1,3}`、标题自定义锚点 `{#id}`（下面都有示例）。
文件开头那段 YAML（front matter）会被**整块忽略**，站点配置只认 `_config.json`。

## 段落与换行

普通段落之间用空行隔开。中文段落里在源码中手动换行不会插入空格：
这一行在源码里另起一行，
渲染后仍然紧贴上一行。

行尾留两个空格则会产生硬换行：  
所以这一行会被顶到下一行，而不是继续贴着上面。

引用（行首 `>`）里可以放列表和代码：

> 引用第一层，任何 Markdown 都能继续写。
>
> - 引用里的列表项
> - 第二项
>
> > 引用还能再嵌一层。

## 行内语法

`行内代码`、**粗体**、*斜体*、***粗斜体***、~~删除线~~。
反引号里的 `<div>` 原样显示为文本，不会被当成 HTML。

中文与下划线边界不会误判：变量*指针、`snake_case`、`a_b_c` 都保持原样。

白名单内的行内 HTML 可以照常使用：按 <kbd>Ctrl</kbd> + <kbd>C</kbd> 复制、<mark>高亮</mark>、H<sub>2</sub>O、x<sup>2</sup>。

裸链接会自动变成链接：https://example.com/path?a=1
尖括号写法也一样：<https://example.com/>

## 标题与锚点

标题从 `#` 到 `######` 共六级。锚点 id 由标题文字生成：去掉标点、空格变成 `-`、字母转小写，
例如上面那个标题的 id 是 `行内语法`，所以可以这样跳：[跳到「表格」](#表格)。

- 同名标题会自动加后缀：第二个 `## 表格` 的 id 是 `表格-1`（本页没有重复标题，两处都碰不到）；
- 想让锚点固定下来（比如别处已经链接过），在标题末尾写 `{#锚点}`，它会顶替自动生成的 id：
  `## 标题文字 {#fixed-id}` 的 id 就是 `fixed-id`，那对大括号标记本身不会显示出来；
- 页内锚点写成 `[文字](#锚点)`，站内跨篇写成 `[文字](其它文档.md#锚点)`。

### 固定锚点演示 {#fixed-id}

这个标题的源码是 `### 固定锚点演示 {#fixed-id}`，所以它的 id 是 `fixed-id` 而不是自动生成的 `固定锚点演示`：
点[这个链接](#fixed-id)会跳到它自己身上，大纲里显示的也是去掉标记后的文字。

## 表格

单元格里的 `|` 要用 `\|` 转义，对齐由分隔行决定：

| 左对齐（默认） | 居中 | 右对齐 | 含竖线 |
| :--- | :---: | ---: | :--- |
| a | b | 1 | 用 `\|` 转义 |
| 中文 | 内容 | 1,234 | 结束 |

> 表格宽了会在正文里横向滚动，而不是把行内代码挤成竖排——手机上尤其明显。

## 列表

1. 有序列表
2. 第二项，可以嵌套：
   - 无序子项（缩进决定层级）
   - 另一个子项
     1. 再嵌一层
     2. 第二小项
3. 第三项

- [x] 表格、列表、引用、代码块
- [x] 提示区块（`::: tip` 等）、代码行高亮、标题自定义锚点
- [x] 脚注、任务列表、原生 HTML
- [ ] 全文搜索（有意不做）

## 引用与代码块

代码块用三个反引号开始，语言名会显示成右上角的标签，并提供复制按钮：

```js
// 注释、字符串、数字、关键字都会被高亮
const name = "示例字符串";
let n = 42;
function add(a, b) { return a + b; }
```

```bash
# 语言名可以随便写，认不出的语言按纯文本处理
python3 -m http.server 8080
git add -A && git commit -m "update docs"
```

行内代码与代码块里的内容**逐字保留**，高亮只加 `span`，不改动文本。

在语言名后面紧跟 `{行号}` 可以给指定行加底色，行号支持单个、区间和逗号（`{3}`、`{1,3-4}`）：

```js{1,3}
// 第 1 行被标了出来
const a = 1;
// 第 3 行也被标了出来
const b = 2;
```

- 那对 `{ }` 不会混进语言标签：右上角显示的仍然是 `JS`；
- 认不出的语言按纯文本处理，行高亮照样生效。

## 提示区块

写法照抄 VuePress：`:::` 加类型开始，单独一行的 `:::` 收尾，里面照常写 Markdown。
不写标题时显示默认标题（提示 / 说明 / 警告 / 危险），想换成自己的标题就写在类型后面。

::: tip
`tip` 没写标题，所以标题用的默认值「提示」。
:::

::: info 标题可以**自定义**
标题里照常解析行内语法（这句的粗体就在标题里），`行内代码` 也一样：[链接](#提示区块)。
:::

::: warning
容器里可以放列表、代码块，也可以再套一层容器：

- 容器里的列表项

```bash
echo "容器里的代码块：里面的 ::: 不会被当成收尾"
```

::: danger
内层容器（不写标题就是默认的「危险」）。
:::
:::

::: details 点开看细节
折叠块用原生 `<details>` / `<summary>`，默认收起。
:::

- 类型只认 `tip`、`info`、`warning`、`danger`、`details`；别名 `note`、`important` 归到 `info`，`caution`、`error` 归到 `danger`；
- 认不出的类型不丢内容：按中性样式渲染，控制台给一条提醒；
- 忘了写收尾的 `:::` 也不会吃掉后面的正文：容器按到文末收尾，控制台提醒一次；
- 嵌套时内层的冒号数**不要超过**外层（同级也行），内层自己收自己。

## 脚注

正文里可以引用同一个脚注两次[^again]，第二次[^again]；也可以另开一条[^other]。

[^again]: 脚注支持行内语法，比如 `行内代码`；
    定义的后续行缩进即可继续写。
[^other]: 第二条脚注。重复引用同一个脚注只会生成一条定义，回跳符号会分列。

## 原生 HTML

块级 HTML 走白名单透传，`<details>` 这类折叠块很适合放「可选细节」：

<details>
<summary>点开看说明（白名单内的 HTML 块原样透传）</summary>
块里的 **星号** 不会被解析成粗体：这是有意为之，避免写出半截 Markdown。

安全起见，`<script>`、`<iframe>` 这类整块丢弃，`on*` 事件属性与 `javascript:`、`data:text/html` 链接一律剥掉。
</details>

## 做不到的事

- **不**支持 setext 标题（`===` 下划线）、引用式链接 `[a][b]`、Obsidian 双链 `[[a]]`、HTML 块内部的 Markdown；
- 提示区块不做 `v-pre`、也不认 VuePress 的 `@` 参数写法，只认上面那几个类型名；
- 文件开头的 YAML front matter 会被**整块忽略**：站点配置写在 `_config.json`（见 [站点配置](../站点配置.md)），正文不需要它；
- 没有全文搜索、mermaid、KaTeX、插件系统、i18n、构建步骤——要这些就上 docsify；
- 代码高亮是内置的简易分词器，覆盖二十余种语言的关键字 / 字符串 / 注释，不是 Prism；
- 需要现代浏览器（ES modules）。
