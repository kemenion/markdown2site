# 侧栏清单

左栏（`#sidebar`）完全由内容根里的 `_sidebar.md` 决定。它用的是 docsify 语法，
已有 docsify 站点的清单可以原样拿来用——本站的清单长这样：

```markdown
- [欢迎](README.md)                            ← 有链接 = 文档项
- 指南                                         ← 纯文本 = 可折叠分类
  - [快速开始](指南/快速开始.md)
  - 写内容                                      ← 分类可以嵌套
    - [支持的语法](指南/写内容/支持的语法.md)
- [docsify 官网](https://docsify.js.org)        ← 外链：新窗口打开
```

## 语法要点

- 清单里的路径和正文里的链接一样，都**相对内容根**（`docs/`），不是相对 `_sidebar.md` 自己；
- `.md` 后缀可以省（会自动补）；缩进决定层级；当前文档自动高亮、所在分类自动展开；
- 有链接的项是文档条目，纯文本项是可折叠分类；
- 分类自己带链接时（`- [名称](路径.md)` 且下面还有子项），该链接会成为组内的第一项，分类标题仍可折叠；
- 改清单只影响左栏：按 URL 直接打开任何 `.md` 都不受它约束；
- 清单里没列的文档照样能访问，只是左栏看不见——**左栏不会自动跟随文件系统，新文档要手写进清单**。

## 分类展开策略

优先级从高到低：

1. **可见性硬规则**：当前文档所在路径上的分类一定展开，`sidebarExpanded` 点名到的分类（及其父链）也一定展开。
   这条只影响显示，**不写** `localStorage`；
2. **用户点击**：记在 `localStorage` 的 `md-site-group-state`（形如 `{"参考":"closed"}`）；
3. **`sidebarExpanded` 的默认值**。

```js
sidebarExpanded: 'all'                  // 全展开（默认值）
sidebarExpanded: 'none'                 // 全收起；打开某文档时它所在的分类会自动展开
sidebarExpanded: ['参考']                // 只展开「参考」，其余收起
sidebarExpanded: ['指南/写内容']          // 只展开「指南 > 写内容」，父链自动展开以便看得见
```

- 名字就是分类在左栏里显示的文字；带 `/` 时按**完整路径链**匹配，只有名字时匹配**任意层级**的同名分类；
- 点名父分类**不会**连带展开子分类；
- 名字写错只会 `console.warn` 一次，不影响其他分类；
- 本站用的是默认值 `'all'`：**左栏的每个目录默认都是展开的**，只有你点过收起才会记住收起状态。

## 左栏只管目录

页面大纲**只在右栏**（收录哪些级别由配置里的 `toc` 决定），左栏里不会出现当前文档的标题：

- 否则同一份标题既在右栏又在左栏，两处各自高亮，左栏还会被撑长；
- 手机上左栏变抽屉、大纲变同一套浮层，见 [界面与移动端](../参考/界面与移动端.md)。
