# 指南总览

本目录是「怎么用」的主线：先让站点跑起来，再按需改配置、调左栏、写内容。
每篇都能单独看，顺序建议如下。

## 从零开始

1. 摆好四件东西：`index.html` 与 `app/`（外壳，与项目无关）放进仓库根，内容目录 `docs/` 里放
   Markdown、`_config.json`（站点配置）与 `_sidebar.md`（左栏清单）；
2. 起一个静态服务（见下）；
3. 编辑 `docs/_sidebar.md`，决定左栏的顺序与分类；
4. 逐篇写正文——写法见 [支持的语法](写内容/支持的语法.md)。

```bash
python3 -m http.server 8080     # 在仓库根目录执行，然后打开 http://localhost:8080/
```

> 走 HTTP 是硬要求：`fetch()` 受同源策略限制，`file://` 下读不到 Markdown。

## 把内容搬去别的项目

`docs/` 就是一个普通目录，站点的一切路径都相对它解析，所以整包搬走不会断链：

- 把新项目的 Markdown 放进它的 `docs/`、写好 `_sidebar.md`，站点立刻变成那个项目的；
- 外壳（`index.html` + `app/`）不必跟着搬，反过来也一样；
- 本页就是个例子：它的地址既可以是 `#/指南/README`（左栏点进来的写法），也可以是 `#/指南/`
  ——站点按「目录落地页统一叫 `README.md`」的规则找到了本文件（规则见 [URL 与路由](../参考/URL与路由.md)）。
